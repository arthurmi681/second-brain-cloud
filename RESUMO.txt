## 🌐 APIs DISPONÍVEIS

### GET /api/memories
Lista todas as memórias salvas

```bash
curl https://second-brain-cloud.vercel.app/api/memories
```

### POST /api/memories
Salva uma nova memória

```bash
curl -X POST https://second-brain-cloud.vercel.app/api/memories \
  -H "Content-Type: application/json" \
  -d '{"message":"Sua mensagem aqui", "category":"general"}'
```
